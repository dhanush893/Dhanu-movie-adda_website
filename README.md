# DHANU MOVIE ADDA

Responsive iPhone-inspired movie discovery website prototype.

## Run
Open `index.html` in a modern browser, or use VS Code Live Server.

## Features
- Premium dark interface with gold accents
- KANNADIGA admin label
- IMDb-style Top 10 starter chart
- Ten horizontal movie collections
- Search by movie title or genre
- Movie details modal
- Watchlist persisted in browser localStorage

## Data and production notes
This starter uses a small sample catalogue. Ratings are illustrative and are **not live IMDb ratings**. For production movie metadata, connect a licensed provider such as TMDB or OMDb and follow its API terms. Do not scrape IMDb. Keep API credentials on a secure backend, never in client-side JavaScript.
